# XKOBO Mobile

A browser (and phone) port of **xkobo 1.9**, the classic fortress-busting shooter by Akira Higuchi.
Plain HTML5 canvas + ES modules – no build step, no dependencies.

## Run it

```bash
python3 serve.py          # then open http://localhost:8000/
```

`serve.py` also prints a LAN address – open that on your phone (same Wi-Fi). Any static file server works
(`python3 -m http.server`, nginx, GitHub Pages…). Service workers and "Add to Home Screen" need HTTPS
(or localhost) when you host it for real.

URL switches: `?cheat` (any stage, unlimited ships, scores not recorded) · `?touch` (force on-screen controls).

## Controls

| | Move | Fire | Pause |
|---|---|---|---|
| Touch | D-pad (bottom-left) | FIRE (bottom-right) | ❚❚ |
| Keyboard | arrows / WASD / numpad | Space, Shift, Z, X | P / Esc (Q quits when paused) |
| Gamepad | stick / d-pad | A/B/X/Y, shoulders | Start |

Your ship never stops: it keeps flying in the direction you last pointed. Fire shoots forwards *and* backwards.

## How it's put together

The game logic is a faithful, module-by-module translation of the original C++ (same fixed-point maths,
same 32-bit RNG, same enemy behaviours) so it plays like the original at the original 30 ms tick.

| File | Original |
|---|---|
| `js/enemy.js` | `enemy.C`, `enemies.C` – all enemy kinds + pool |
| `js/myship.js` | `myship.C` |
| `js/manage.js` | `manage.C` – title/play/pause, lives, bonus ships |
| `js/screen.js`, `js/map.js` | `screen.C`, `map.C` – maze fortress generation, backing store |
| `js/scenes.js` | `scenes.C` – the 50 stages (generated by `tools/gen_scenes.py`) |
| `js/radar.js`, `js/random.js`, `js/key.js` | `radar.C`, `random.h`, `key.C` |

New for the web: `render.js` (playfield → canvas), `input.js` (keyboard / touch / gamepad), `main.js`
(loop, HUD, menus), `attract.js` (splash), `storage.js` (hi-scores in `localStorage`), `sw.js` + `manifest.webmanifest` (offline / installable).
`assets/sprites.png` is `xkp256.tif` converted; pure red `(255,0,0)` is the transparent colour.
